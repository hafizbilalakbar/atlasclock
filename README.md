

| [Vercel](https://vercel.com/) | Free Serverless | Next.js, React, SSG, API routes |
| [Netlify](https://netlify.com/) | Free Static + Functions | JAMstack, SPAs, forms |

| [Render](https://render.com/) | Free Tier Backend | APIs, workers, cron jobs |

```bash

npm run build

# Deploy to GitHub Pages
# Go to Settings → Pages → set branch to main/docs/gh-pages

# Or deploy to Vercel
npx vercel --prod
```
